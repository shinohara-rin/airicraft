# Remote tool materials

The evaluator builds a lit-route fixture with a two-use stone pickaxe, three cobblestone, and torches. Two stone cells obstruct the passage 25 blocks into the cave; ore lies beyond its end. Oak logs and a crafting table remain at the entrance. No sticks or planks are supplied.

This tests whether replacement-tool acquisition retraces the observed route for missing materials and returns to the suspended exploration. Goal inventory and replacement suspension/resumption are mandatory. Inspect the decision tape to establish the outward/return travel; a scenario PASS alone does not establish that route. This is a capability fixture, not a frozen-seed release result.
